# Studio bounded context

Bounded context dedicated to the studio/producer module of CINAF v2.

Phase A (Agent 1): folder placeholder only — no controllers/services yet.
Subsequent agents (2 onwards) will populate this namespace with controllers,
services, and DTOs that operate on the `Studio` and `WithdrawalRequest`
entities defined in `App\Entity`.

This README is intentionally short — it exists to document the intent of
the directory until the first real class lands here.
